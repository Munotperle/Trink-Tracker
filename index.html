    Noch nichts eingetragen. Tipp oben auf ein Getränk, um es hinzuzufügen.

    Statistik

    0.0 L pro Tag

    Ziel

    Durchschnitte zählen ab dem Tag deines ersten Eintrags, damit ein neuer Start den Wert nicht künstlich senkt. Die Jahresansicht zeigt pro Monat den Durchschnitt pro Tag.

    Einstellungen

    2.5 L

    Gezählt wird die effektive Wassermenge, also Menge mal Anrechnungsfaktor.

    Erinnerungen

    Zur eingestellten Zeit erscheint ein Hinweis mit Tropfen-Ton, falls du die Menge noch nicht erreicht hast. Das funktioniert, solange die App geöffnet ist.

    Datensicherung

    Deine Daten liegen nur auf diesem Gerät. Sichere sie regelmässig, damit du sie wiederherstellen kannst.

    Alle Daten löschen

    Entfernt alle Einträge von diesem Gerät. Exportiere vorher, wenn du sie behalten möchtest.
